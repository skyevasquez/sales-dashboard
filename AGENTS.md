# Sales Dashboard

Modern sales tracking and analytics dashboard for multi-store KPI management.

## Quick Reference
- **Package Manager:** npm
- **Dev:** `npm run dev` (Next.js)
- **Convex Dev:** `npx convex dev`
- **Build:** `npm run build`
- **Start:** `npm start`
- **Lint:** `npm run lint`
